**判断标准（摘自规则卡）。** 三项全部满足才走快速通道：1）病历确认因脊髓损伤导致双腿功能完全丧失，或确认为小细胞肺癌；2）该结论出自审核机构直接从医院或诊所取得的病历；3）脊髓损伤的功能丧失已连续持续至少 3 个月。

| 术语 | 含义 |
| --- | --- |
| C、T、L、S 节段 | 脊柱的各部分：C 颈部，T 胸部（T1-T12），L 腰部，S 骶部（最下端）。 |
| 脊髓损伤（SCI） | 脊髓受损；脊髓是脊柱内部的神经束。 |
| 椎间盘膨出或突出、DDD、神经根病 | 椎间盘或神经根的问题。 |
| AIS 分级（ISNCSCI 检查） | A = 完全性（损伤平面以下无运动、无感觉，包括 S4-S5）；B = 仅有感觉；C、D = 有部分运动；E = 正常。 |
| 截瘫 / 下肢轻瘫 | 双腿瘫痪 / 双腿无力。 |
| 肌力 0-5；LEMS 0-50 | 肌力：0 为无，5 为正常。LEMS 为双腿肌力总分：0 为无，50 为正常。 |
| 痉挛、阵挛、抽搐 | 不受意识控制的肌肉僵硬或动作。 |
| 小细胞肺癌 | 也写作 SCLC、小细胞癌、燕麦细胞癌。 |
| NSCLC | 非小细胞肺癌：腺癌、鳞状细胞癌、大细胞癌。 |
| 原发 / 转移性 | 癌症起始的器官 / 已扩散到其他器官的癌症。 |
| 病理报告 | 对组织（活检）的化验检查。其最终诊断写明癌症类型。 |
| 肿块、结节、病灶 | 影像（X 光、CT、MRI、PET）上看到的异常。 |
| 可疑、R/O（待排除）、可能 | 表示尚未确认的可能性。 |
| HPI、评估 / 印象 | 患者自述 / 医生的结论。 |
| bilat、LE、ED、PCP | 双侧、下肢、急诊科、初级保健医生。 |
| HIT、ERE | 审核机构以电子方式接收病历的渠道。 |
