**Criteria (from the rule card).** Fast track only if all three are met: 1) the records confirm complete loss of function in both legs from a spinal cord injury, or small cell lung cancer; 2) that finding is in records the agency obtained from a hospital or clinic; 3) for the spinal cord injury, the loss has lasted at least 3 continuous months.

| Term | Meaning |
| --- | --- |
| C, T, L, S levels | Parts of the spine: C neck, T chest (T1-T12), L lower back, S bottom. |
| Spinal cord injury (SCI) | Damage to the spinal cord, the nerve bundle inside the spine. |
| Disc bulge, extrusion, DDD, radiculopathy | Problems of the spinal discs or a nerve root. |
| AIS grade (ISNCSCI exam) | A = complete (no movement or feeling below the injury, incl. S4-S5); B = feeling only; C, D = some movement; E = normal. |
| Paraplegia / paraparesis | Paralysis / weakness of both legs. |
| Strength 0-5; LEMS 0-50 | Muscle strength: 0 none, 5 normal. LEMS adds the leg muscles of both legs: 0 none, 50 normal. |
| Spasticity, clonus, spasms | Involuntary muscle stiffness or movement. |
| Small cell lung cancer | Also written SCLC, small cell carcinoma, oat cell carcinoma. |
| NSCLC | Non-small cell lung cancer: adenocarcinoma, squamous cell, large cell. |
| Primary / metastatic | Where a cancer started / cancer that has spread to another organ. |
| Pathology report | Lab exam of tissue (biopsy). Its final diagnosis names the cancer type. |
| Mass, nodule, lesion | Something seen on a scan (X-ray, CT, MRI, PET). |
| Suspicious for, R/O, likely | Words for a possibility that is not yet confirmed. |
| HPI, Assessment / Impression | Patient's own account / the clinician's conclusion. |
| bilat, LE, ED, PCP | Both sides, legs, emergency department, primary care provider. |
| HIT, ERE | Electronic routes by which the agency receives records. |
