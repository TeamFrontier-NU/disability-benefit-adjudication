# SSDI 快车道规则卡

在这项模拟中，你是州残疾认定机构的社会保障残疾保险（SSDI）初筛审核员。请根据申请表和病历，判断是否推荐申请进入快车道。

- **进入快车道（是）：** 现有资料齐全，足以按本研究规则明确判断申请人符合资格，因此优先处理申请，加快审核。
- **常规审核（否）：** 现有资料不足以作出明确判断，或不符合快车道条件。申请按常规流程继续审核，必要时补充材料，并不代表拒绝。

### 1. 看病情：病历确认了什么？

| 病情 | 在本研究中怎么看 |
| --- | --- |
| 脊髓损伤 | 病历明确记录因脊髓损伤导致**双腿功能完全丧失**，才可能进入快车道。仅写背部受伤、腿无力或使用轮椅，证据还不够。 |
| 肺癌 | 病历明确确诊**小细胞肺癌**，才满足这条快车道规则。仅写疑似肺癌、肺部有肿块，或未注明肺癌类型，需要进一步审核。 |
| 腿扭伤 | 腿扭伤本身不符合本研究的快车道条件。 |
| 腰痛 | 腰痛本身不符合本研究的快车道条件。 |

### 2. 看来源：关键病情由谁证实？

| 证据来源 | 怎么用 |
| --- | --- |
| 州机构直接向医院或诊所调取的病历 | **可以用来确认病情。** 机构能核实记录由哪家医疗机构提供。 |
| 申请人自行提交的材料或家属说明 | **只作参考。** 如果关键病情只出现在这些材料里，走常规审核。 |

### 3. 看时长：影响工作能力的状况持续了多久？

| 病情 | 时长要求 |
| --- | --- |
| 脊髓损伤 | 双腿功能已连续完全丧失**至少 3 个月**，从功能丧失开始算。未满 3 个月或记录不清楚，需进一步审核。 |
| 小细胞肺癌 | 直接调取的病历一旦明确确诊，**无需等待 3 个月**。 |

病情、来源和适用的时长要求都满足，才推荐进入快车道。
